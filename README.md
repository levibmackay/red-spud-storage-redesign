# Red Spud Storage — Redesign Mockup

A redesign pitch mockup for Red Spud Storage, a self-storage facility in
Rexburg, Idaho. This is not the live site — it's a design proposal built to
show the owner a different direction.

Marked `noindex` and deployed separately from the real site so it never
competes with it in search.

## Stack

- Vite + React
- Tailwind CSS
- Framer Motion
- Self-hosted fonts via Fontsource (Archivo Variable, Chivo)

## Development

```
npm install
npm run dev
```

## Build

```
npm run build
```

Deploys automatically to GitHub Pages on push to `main` via
`.github/workflows/deploy.yml`.
